# Contributing

Bug reports, compatibility results, and feature proposals are welcome.

External code contributions are not accepted yet. SERPsmith uses AGPLv3 plus
a separate commercial-license path, so the project needs a contributor
agreement that preserves the copyright holder's ability to distribute
contributions under both licensing models.

Until that agreement is published:

- open issues for bugs or proposals;
- do not submit code, documentation, images, adapters, or other copyrightable
  pull requests;
- never include credentials, private site profiles, unpublished content,
  operational state, or personal data.

This policy will be revised before outside pull requests are accepted.
